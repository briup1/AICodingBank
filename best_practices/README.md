# 最佳实践记录

保存“这类问题如何被处理”的案例，以及从提示词、清单和笔记中提炼的可复用方法；讲清主题、预期效果和用法，不只是堆原文，也不以是否已有实测决定能否收录。它不是岗位流水账或第二份业务代码。完整规范只在 [STANDARD.md](STANDARD.md)，新记录使用 [TEMPLATE.md](TEMPLATE.md)。

使用链：遇到问题先查已有记录 → 无适用答案则研究/尝试 → 解决并验证 → 更新记录 → 必要时将稳定操作提炼成 Skill。失败路径和未知项一并保留。
