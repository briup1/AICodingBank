# Codex CLI：从能启动到可信工具执行与报告接入

**接入 Codex 的本质是接入一个可执行、需约束和验真的 Agent，不是调用一次文本生成接口。** 最重要的成功标准不是“启动了、退出0、返回JSON”，而是“确实读取本次输入，执行有记录，报告有依据，失败不冒充成功”。

## 问题与适用条件

案例目标：本地 Git 新提交自动排队，由 `codex exec --json` 调查代码并生成可信报告；Runner 管调度、权限、生命周期与校验，Codex 管调查，模型提供推理。大屏只是结果视图，不是接入成功的证据。

```text
指定提交 → 独立输入快照 → Codex真实工具执行 → 事件/退出证据
                                              ↓
                       身份、源码引用、执行声明校验 → 保存报告
```

适用于把 Codex CLI 嵌入评审、分析或批处理服务。以下配置方案只在上述版本与环境验证，不能当作所有版本的通用配方。

## 为什么波折：调查与尝试

| 波折 | 证据与原因 | 最后处理 |
| --- | --- | --- |
| CLI能启动，却不能读取代码 | 日志报 `code-mode host is disabled`，没有命令事件。模型目录可指定 `code_mode_only`，优先于关闭 `features.code_mode`；开关关掉不等于切回普通工具 | 单次进程使用 `model_catalog_json`，保留模型、指令及其他metadata，仅改 `tool_mode=direct`；Host继续禁用 |
| 退出1却无法定位 | stderr只剩字节数；非0路径原先跳过末尾事件排空 | 各退出路径均排空流，记录退出码、末事件、成功命令数、截断/残留；只保存固定安全诊断，未知stderr不原样落盘 |
| 工具失败，模型仍输出完整JSON | 引用了不存在的文件，声称做过检查却没有命令事件 | 不接受自述为证据；保留失败并拒绝报告，而不是放宽校验 |
| 工具恢复后仍有接入摩擦 | 裁剪环境后需提供可用PATH；模型还曾抄错提交SHA | 只设置Python及系统目录PATH；本次schema用enum固定attempt/base/target身份，之后仍独立核对 |

首次退出1的原始stderr已经丢失，**不能倒推其唯一原因已被证明**；后一次明确的工具错误和修复后的成功，是更窄的已验证结论。

## 当前推荐路径：先证明能做，再做完整任务

1. **零模型核对**：固定CLI版本，核对实际模型工具模式、MCP/扩展、只读目录、网络、审批与最小环境。帮助/预检通过不能证明工具可执行；本版本`debug prompt-input`不导出工具定义。
2. **最小真实canary**：创建提示词中不透露内容的随机文件，要求工具读取；在隔离合成目录验证禁写、越界读拒绝。核对真实命令事件及结果，不能只看回答正确。
3. **一个可信报告**：按本次身份约束输出；核对源码路径/行号、实际命令、退出码和观察结果。发布成功前要求完整事件流、正常结束及成功命令证据。
4. **三个质量样本**：已知缺陷应找出，修正负例不再报旧缺陷，缺权威规则时明确提问，不编造业务判据。
5. **再接连续运行**：验证FIFO、去重、失败隔离、持久化恢复和有限预算。保持“调度可靠”“模型执行真实”“分析判断正确”分层验收。

## 踩坑与未采用路径

- 不一开始就在完整业务任务上反复重试。先排除工具/环境问题，再排查报告契约与质量，每次重试要有新证据或明确假设。
- 不为消除警告直接启用Host、放开全部权限、修改全局配置或迁移SDK。本次单任务direct模式足够；其他版本若不支持，重新评估，不能硬套。
- 不把正则脱敏当安全保证：凭据可能跨stderr分块；本次改为完整行的固定诊断分类，其余仅存字节数。也不据此宣称所有日志通道已全面脱敏。
- 不离线修正模型JSON再记为真实成功；身份抄错就拒收，用schema约束降低下次出错概率，失败历史保留。

## 验证与未覆盖

本次真实调用6次：工具canary 1次、原任务诊断/复验2次、连续样本3次；最终4份报告校验并回读成功。3个新增提交自动串行处理，缺陷/负例/缺规则逐份抽查。80项本地测试通过；恢复故障采用真实本地进程＋fake执行器，**不算真实模型中途故障通过**。

源码引用有效不等于推理正确；命令输出匹配不等于通用脚本语义证明。没有验证跨天稳定性、机器重启、开机自启、公司接入或独立Review；单次canary不证明完整沙箱安全。因此记录为`partial`，不是生产成熟度背书。

## 下次使用与失效条件

从“当前版本事实 → 随机文件canary → 单报告 → 三类样本 → 连续链”开始。CLI升级、模型/网关/工具模式/权限/环境变化后重验受影响部分；不要照抄本机路径或继承旧模型调用及代码发送授权。即使测试不限调用次数，也保留超时和内部保险丝，避免无限重试。
