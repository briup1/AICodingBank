# Harness：从目录整理恢复为可指导开发的工程手册

## 现状与目标

本次是 Skill 行为与文档变更，无业务页面变化；不把博客截图当作本项目运行结果。用户先授权优化本工作台技能，随后纠正将“精简”解释为删除完整范文的方案，明确授权：阅读全文独立评估，由一个执行者采用其最小推荐完成修改及验证，不再委派。不含其他项目写入、安装、提交或发布。本文整理现行目标，正式需求/用例基线未另经独立审查及人工批准，不因实施授权伪造 approved。

现状：读取项目入口 → 映射资料/按需查证 → 填固定章节 → 结构检查与代表链回读。主要风险是未充分调查就缩小到“当前已知”，单条范文被当作覆盖上限，暂缺资料在首个实现后未补齐。

目标：识别本次覆盖的主要模块/能力/数据和交互边界 → 依据实际项目生成可操作规则及 Wiki → 分别验结构与内容 → 首次实现后按变化补齐暂缺项。

## 需求重定义

- 最终目标：不熟悉项目的人或 Agent 能通过手册知道功能放哪、复用什么、不能破坏什么、业务/状态怎么流转、改后怎么验证。
- 不追求：复制商城的 Java/Vue 分层，或生成相同数量、相同长度的文件。
- 用户故事：作为跨项目开发负责人，我希望初始化后的资料能指导下一次真实改动，而非每次仍从源码盲搜；作为接手者，我希望明确哪些内容已覆盖、哪些缺口会阻塞任务，不把诚实声明未知误当作资料已齐备。
- 取舍：保留按需读取、权威正文唯一、未知不编造、安全与授权边界；保留内容标准＋薄模板＋按需完整范文，不恢复旧版全量字段复制、中央编号、默认多 Agent 探查。精简重复维护和默认读取量，不削弱完整成稿的示范价值；安全和结构统一不是将能力降为资料整理的理由。

## 新旧差异

| 差异 | 旧链路 → 本次目标 | 后续影响 |
|---|---|---|
| D01 调查 | 缺依据时定点查证 → 先识别声明范围内主要对象，再定点核对 | 未调查不能当不存在，局部产物不能声称全项目完成 |
| D02 规则 | 职责/约束摘要 → 对主要改动类型给放置、命名、复用入口、边界和参考写法 | 新增功能不再依赖重新盲搜 |
| D03 Wiki | 一条代表流程即可示范 → 重要能力、状态与交互覆盖可定位 | 单条范文只教表达，不代替整体覆盖 |
| D04 验收 | 结构通过容易被误读 → 结构检查与人工任务回读分别报告 | 空泛但结构正确的文档仍不可报可接手 |
| D05 维护 | 主要更新已有正文 → 本次使暂缺失效时也补建正文和更新入口 | 首次实现后不继续保留“暂无代码” |
| D06 收敛纠正 | 前执行者删除八份范文、内联短例的方案已被用户纠正 → 内容标准维护生成要求，模板只留骨架/短提示，完整范文按需读取 | 八份沿原路径重建，保留成品代码/表格/完整链与互链；两入口直接导航，不要求普通局部同步全读；二级章节不变 |
| D07 范围与扩展 | 旧范文声称新增/查看/完成但只展开完成 → 统一虚构局部输入，明确仅示范完成操作，并补未来取消完成的扩展落点 | 拟采用的命名/导出/页面绑定及联动更新不写成已实现能力，不以局部范文替代全项目调查 |

## 规则与边界

- R01：通用的是需要回答的开发问题，不是统一技术栈。新项目无实现时保留具体暂缺和补齐时点，不虚构架构。
- R02：已有项目初始化覆盖声明范围内主要模块、能力与边界。已有 Owner 回读后复用，不能因为链接存在就当完整。
- R03：规则区分已确认与默认实践；项目具体写法可指导开发，但不能由出现次数推导强制红线。
- R04：已有 schema/OpenAPI 等不抄全集；缺正式契约时写足调用必需语义，不能只让读者去找源码。
- R05：固定标题及二级章节不变，保留既有结构兼容。检查器继续只读和只验结构，不新增伪语义自动评分。
- R06：sync 只处理本次影响的资料及暂缺项，公共结构迁移仍须授权；普通样式修正无稳定变化时可无需同步。
- R07：结构/提示/手写夹具验证不替代真实 setup→sync 验证；本次不全局安装，verified 保持空。

## 验收与执行约定

本轮聚焦验证：[验收场景与结果](acceptance.md)。这是技能回归与静态任务回读记录，不是业务页面用例，也不是已独立确认的正式用例基线。

- 使用现有 Python 3.12.9 环境；不安装依赖，不启动服务，不修改业务项目。
- 验固定章节兼容、必要范文可定位、相对链接与章节锚点、范文结构兼容、空泛正文反例、两个入口的按需导航和内容标准引用、交付后维护路由。检查器继续只读/只验结构；手写夹具只证明兼容/只读，不冒充 setup 或 sync 执行效果。
- 人工核对空项目→首次实现、已有多模块项目、局部样式改动、共享项目个人接入及结构通过但内容空泛的场景；推演不冒充真实 Agent 生成验收。
- 不做：新增技能入口/引擎、批量迁移业务项目、安装、上传、提交、发布、真实页面操作、代用户批准规则。
