# 岗位运行验收用例 v1

批准依据：本轮用户确认的按需复用及恢复闭环。仅验证本地任务；不得抢占或关闭其他会话。独立用例审查未执行。

| 用例 | 对应 | 操作与预期 |
| --- | --- | --- |
| T01 | D01/D05 | 创建目标为读取指定本地说明的任务，退出命令进程再 show/recover：目标、范围、依据、完成标准保持一致，无自动执行 |
| T02 | D02 | 首次派单：创建 Pi/high 实例并记录真实身份；已验收后同项目岗位新任务可复用同一实例 |
| T03 | D02/D05 | 实例 busy、身份不符、未验收旧任务或重复派单：拒绝覆盖，不重复发送 |
| T04 | D03/D04 | 保存 submitted 与产物引用：尚未验收；项目经理核对并写验收说明后才 accepted；Herdr idle/done 不自动完成 |
| T05 | D03/D05 | 提交 blocked、原因及下一步，重新运行恢复命令：能看到阻塞及责任；不自动重派 |
| T06 | D02/D05 | 模拟发送超时或启动后进程中断：保留待核对记录，普通再次派单不得重放；明确确认后才恢复 |
| T07 | D01/D03 | 并发更新及无效输入：不丢已有记录、不产生半个 JSON；拒绝缺失范围/标准的任务包 |

真实启动、复用与跨进程读取使用真实 Herdr 验证；故障和并发用隔离模拟验证，不在其他真实任务上注入故障。
