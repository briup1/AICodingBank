# 工作台目录中文地图

> 用途：每个目录名一眼看不懂时查这里。目录名保持英文是刻意选择（原因见文末），中文解释以本文件为准。
> 更新：2026-10-19。

## 一句话

这个仓库不是业务代码仓库，是「AI 装备库 + 装配车间」：管的是给 AI 用的技能、岗位、规则，以及把技能装进各 AI 工具（Claude Code / Codex / opencode / Pi）的流程。真正写业务代码发生在别的项目里。

## 整条链路

```text
技能正文在哪             花名册（登记）              装配                     AI 会话
────────────────────────────────────────────────────────────────────────────────────
tools/skills/  ──┐
（自研技能正文）  │
                 ├──► skills.yaml ────────┐
                 │    （自研登记）         │
vendor/  ────────┤                         ├─► install.py ──► 软链到宿主目录 ──► 加载
（第三方进货缓存）│                         │   （装配器）     ~/.claude/skills 等
                 └──► skills-lock.json ───┘                   （全机 126 条软链）
                      （第三方登记）
```

要点：**技能正文永远只有一份**；宿主目录里放的都是"指针"（软链接）。所以目录改名会让全部指针断掉，这是目录名不能随便改的根本原因。

## 先分清：哪些是"活的"，哪些是"档案"

- **日常会碰（活）**：说明书一套（AGENTS.md 等）、两份花名册、install.py、tools/、roles/、personal/
- **平时不碰（档案/缓存）**：docs/、best_practices/、vendor/、tests/、.local/、各工具本地目录

## 重点目录详解

### vendor/ — 第三方"进货缓存"

从 GitHub 拉下来的第三方仓库存档，目录名格式「作者__仓库」，带 `__ref__版本` 表示锁定了版本。它是登记表（skills-lock.json）指向的实体，也是升级对照和来源证据。**不进 Git、勿手改**，删了登记就是死链。

| --- | --- | --- |
| mattpocock__skills | mattpocock 技能全家桶（审查、诊断、领域建模等） | 27 |
| CopilotKit__CopilotKit | CopilotKit / A2UI 声明式界面 | 15 |
| Leonxlnx__taste-skill | 高端视觉设计三件套 | 3 |
| 312362115__claude | diagram 图表技能 | 1 |
| fastapi__fastapi | FastAPI 官方仓库 | 1 |
| herdrdev__herdr__ref__v0.8.2 | Herdr 终端复用器文档技能（锁 v0.8.2） | 1 |
| langfuse__skills | Langfuse 可观测性 | 1 |

### .local/ 与各工具目录

- `.local/`：本机专属账本（迁移证据、宿主软链快照），Git 忽略；records/、sessions/ 是有意的空占位。
- `.agents/skills/`、`.claude/skills/`：项目级技能入口，里面是指向 tools/skills 的软链，不是正文。
- `.pi/settings.json`、`.apifox/`：各工具自己的配置，与技能体系无关。

## 为什么目录名保持英文（不改成中文）

目录名是**工具链的接口**，不是给人看的标签，实测有 4 条引用链盯着它们：

```text
名字              谁在按这个名字找它                             数量
tools/skills/  ←  skills.yaml 每条技能的 path 字段                全部自研技能
               ←  install.py 建的宿主软链                          126 条
               ←  4 个用户级配置写死绝对路径（pre-push/opencode/pi/codex hooks）
vendor/        ←  ~/.codex/hooks.json 写死 ponytail 钩子路径      2 个脚本
docs/migrations/ ← tests/*.py 硬编码路径核对搬家结果               50 处引用
```

加上非 ASCII 路径在部分工具/脚本里兼容性没有保证、Git 对中文路径输出转义乱码，改名的收益（好看）远小于代价（断链事故）。**约定**：目录名用英文小写+连字符；中文说明写进本文件；文档类文件名可以用中文（如本文件、插件收录登记.md）。
