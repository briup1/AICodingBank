怎么把图形描述给 AI

图形选对之后，描述里固定给这五样，AI 出的图基本不用返工。

1 · 图名 + 变体
“UML 时序图”“C4 容器图”“泳道图（3 条泳道）”
不要只说“画个图”
2 · 目的 + 读者
“给运维看部署拓扑”“给产品看状态流转”
不要省掉读者
3 · 参与者 / 元素清单
逐个列出：服务名、角色、表名、状态名
不要给“一些服务”
4 · 关系与顺序
谁调谁、同步/异步、条件分支、异常与补偿
不要漏异常路径
5 · 输出格式 + 边界
“Mermaid sequenceDiagram”“不要画字段细节”
不要不设边界

每张图形详情里已按这个结构写好模板，填【】里的内容即可。

形态示意为手绘示意图，用来认形状，不是渲染结果。分类参考 C4 model（Simon Brown）、Microsoft Azure Well-Architected 图表指南、UML 2.5.1 与 BPMN 2.0 的常用口径。
