## 必要限制

- 登记之前、标记之前、新标记未同步，不保证识别；安装不自动启用仓库。
- pull 的未来远端 tip无法离线证明，已登记仓库要求 fetch 后再单独 merge/rebase 明确引用。
- 任意脚本/解释器/远端 MCP 中隐藏的 Git 操作不保证执行前覆盖；保留血缘的结果由 pre-push兜底。
- 不保留血缘的 squash/cherry-pick/手工复制事后不能可靠归因。明确来源包含标记时可以提前拒绝。
- Hook同用户权限，可以被禁用；不是服务端或 OS 安全边界。
- 工作台根 AGENTS.md/CLAUDE.md 现有内容不同；本次未改二者，不将既有差异混入本需求。
