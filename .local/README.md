# 本机运行记录（未启用）

本文件可版本化；其他内容由 Git 忽略。sessions/ 与 records/ 按需生成，本轮只建立空目录，不生成真实会话或工作记录，不安装自动归档程序。

## 归宿

- sessions/：开工时使用的角色实例、会话引用、就绪与恢复信息。运行快照不能当成任务完成证据。
- records/：岗位任务摘要与项目记录的引用。不复制项目代码、测试日志或完整对话；没有项目的纯调研可以在经授权的目标文档中保存产物。
- 项目/任务原有 progress、验收记录与产物仍是事实来源，Pi Goal/看板等原状态系统不被替代。本目录是本机索引，不再维护另一份权威任务状态。

## 记录节点和最小字段

接单、阻塞/重要交接、提交交付、核验结果变化时记录；不逐命令记流水账。每条包含：任务标识、岗位与实例、时间、范围/版本、状态摘要、产物和证据指针、阻塞/未覆盖、下一步与责任人。

“已提交交付”不等于“已核验完成”；失败与返工也保留，更新时引用来源版本和核验者。项目经理汇总既有事实，不将角色自报升级为验收。会话结束前保存足够恢复的信息，不在每次开工加载全部历史。

可复用的问题解决过程按 [最佳实践规范](../best_practices/STANDARD.md)归档，运行记录只保留案例指针；稳定方法才考虑提炼成 Skill。不把所有进度自动当最佳实践。自动归档仍未实现，需明确触发、写入责任和验证。

## 隐私与生命周期

不保存凭证、客户敏感资料或完整会话。只引用获准读取的证据，不以 Git 忽略作为安全控制。本地记录不随 Git 同步，也未提供自动备份、保留期或删除机制；清理需确认，不因“收工”删除证据。
