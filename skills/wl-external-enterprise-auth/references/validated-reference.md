# 已验证参考：独立产品接入企业身份

## 参考项目

Yuxi 是一套独立于外部公司平台的知识智能体系统。本参考只记录可迁移的工程事实，不记录外部地址、凭证、用户资料或项目本地路径。

## 已验证链路

```text
外部公司登录
  -> 固定 callback
  -> state、浏览器 binding、provider 和回调隐私校验
  -> 服务端身份核验
  -> 本地产品 Session
  -> 产品用户与企业归属
  -> ExecutionPrincipal
  -> ProductExecutionGrant
  -> Request / FIFO / Run / Worker
```

实际实现将外部身份与内部管理平台账号分开，产品请求没有使用内部管理员身份执行。已验证的本地认证测试覆盖普通登录、显式重新认证、回调重放、错误 binding、Cookie 轮换和旧会话失效；产品执行测试覆盖主体作用域、Grant 归属、产品资源和知识工具清单。

## 可迁移结论

- 普通 SSO 与显式重新认证必须是两个明确意图；重新认证使用外部系统确认过的 logout 或强制认证入口。
- 外部身份返回值必须经过服务端最小字段映射；客户端身份字段不能覆盖可信结果。
- Session 是本地登录状态，不能直接等同外部凭证；后台执行使用本地 Subject 与 Grant。
- Grant 在请求提交时固定，后续 Request、Run、Worker 和结果沿用同一授权快照。
- 产品授权、企业授权和内部管理平台权限是不同边界。
- 能力清单必须显式配置；拥有某个资源不自动获得全部相关工具。

## 仍需重新验证

每个新项目都要重新核对：

- 外部 Provider 的 callback、logout 和身份核验契约；
- 个人身份、企业切换、撤权和凭证失效规则；
- 本项目的 Request / Job / Run / Worker 生命周期；
- 真实浏览器、真实 HTTP、文件副作用和目标环境证据；
- 上游故障、同浏览器其他系统会话影响和多用户跨企业场景。

Yuxi 的测试结果不能直接替代新项目的验收证据。
