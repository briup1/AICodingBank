# 单元测试 CI 技能

> 状态：草案（待人工确认）

## 概述
在持续集成阶段强制执行测试覆盖率与质量门禁，拒绝低质量代码合入。

## 触发条件
代码推送 / PR 创建时由 CI 流水线自动执行。

## 执行标准

### 1. 覆盖率门槛
- 整体覆盖率 ≥ {待填，如 80%}。
- 核心业务模块 ≥ {待填，如 90%}（模块清单见 `wiki/业务模型.md`）。
- 本次变更新增代码覆盖率 ≥ {待填，如 70%}。

### 2. 测试执行规范
- 外部依赖全部 Mock，禁止单测依赖真实环境。
- 断言严格：比较期望值并带明确错误信息；禁止模糊断言（如仅 `assertNotNull`）。

### 3. 坏味道检查（Anti-Patterns）
- 无断言测试视为无效测试，直接失败。
- 生产分支禁止使用跳过注解（`@Ignore` / `skip` 等）。
- 单个测试方法过长（>{待填} 行）→ 拆分，逻辑必须单一。

### 4. 测试报告输出
- 生成覆盖率报告，高亮未覆盖行。
- 未过门槛 → 构建失败，并提示开发者补充哪些用例。

## 输出
- 通过 / 失败 + 覆盖率数据 + 未覆盖热点清单。
