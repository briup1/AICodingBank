# 部署验证技能

> 状态：草案（待人工确认）

## 概述
部署到（类）生产环境后自动执行验证，确认服务可用、依赖正常。

## 触发条件
新版本部署完成后自动激活。

## 执行步骤

### Step 1: 环境健康检查
- 服务进程/实例状态正常；健康检查端点返回预期。
- 日志无启动期致命错误。

### Step 2: API 冒烟测试
- 按 `wiki/接口协议.md` 的核心接口清单跑冒烟：主路径 + 鉴权失败路径。
- 响应结构符合统一协议。

### Step 3: 基础设施依赖验证
- 数据库连通、缓存连通、消息队列收发正常（各做一次真实读写/收发验证）。

### Step 4: 监控告警确认
- 关键指标无异常飙升（错误率/延迟/资源占用）。
- 告警通道畅通（必要时发一条测试告警）。

## 输出
- 验证报告：每项通过/失败；失败项附现场信息并立即回滚或降级（按 {待填：项目回滚策略}）。
