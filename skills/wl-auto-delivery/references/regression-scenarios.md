# 总流程聚焦回归场景

这些是规范修改后的人工推演输入/预期，不是已经完成的独立审查、网页操作或真实业务 E2E。结构单测通过也不能填写 verified。

| 输入 | 应观察的交接与停止点 |
| --- | --- |
| 只读调查/简单明确修改 | Observe 可结束，明确修改可直接 Execute，不强制完整流水线 |
| 单独调用 QA，有已确认需求，无 HTML 工具 | 只交付 Markdown 与缺口后停止；保留五步、字段/停止，不以前置 HTML 生成卡住；调用方随后负责同源阅读页 |
| 需求含业务 A/B 两部分 | 默认 test-cases.wl-qa-test-planner.md 为唯一正文，同源 HTML 按 A/B 分组并同步版本；需求 HTML 整体相对链接到实际存在的阅读页；历史名称沿实际文件，不抄 AC/TC 双正文 |
| 正式用例含遗漏、无依据场景、重复和未知边界 | 独立审查双向核对、适用性、可执行性和重复；未知预期阻塞，不扩无关测试 |
| Grill 确定原未知规则 | 先回写需求，再查受影响用例并复核确认；不只改测试预期 |
| 未委托方案决策，只有需求批准 | 明确推荐及理由，保持 draft 等待人工方案批准，不自动进入工单 |
| 明确委托且有本版范围、数据、成本、操作边界和关键证据 | 独立记录 delegation_evidence，adopted 交接；不伪造 approved |
| 缺委托证据/人工批准/关键假设证据，或重大不可逆、授权变化 | 停止交接并补证/确认，不能靠 status 字符串推进 |
| 实现完成，同时有无关历史债务 | focused-delivery 只核本版设计、diff、直接依赖和交付阻断问题；证据不足明确不能判定，无关债务不阻断 |
| 约定 Beta，只有本地通过，Beta 不可访问 | 记环境阻塞，不静默换 Dev，不把本地标 Beta 已验收 |
| 一条失败，修复后复测 | 新 run 链旧 run 与缺陷，原失败和未执行保留，不改标准凑通过 |
| 合入 master 未发布/未关闭 | 不进入证据到期删除 |
| 发布关闭但 hold、缺陷或待复测仍在，或保留建议未确认 | 仍保留，仅预览；7/30 天不自动生效 |
| Worktree 将回收 | 外部运行证据和长期摘要能解释各条结论；必要记录未保存就阻塞回收 |
| 尚有失败/阻塞/未执行，想先标 done | 不算完成，所有适用用例通过才可 done；不适用须已确认依据，Agent 不自行接受缺口；环境通过不代表发布 |
| 切换会话，progress.md 写“已确认”但实际文件版本变了 | 核对实际产物/版本、确认范围、当前阶段、未决项/下一步和 run 链接；不凭旧摘要推进，不建流程 DB |
| 创建/复用 Worktree、集成/记环境结果/回收，或仅写文档 | 前者按需加载 wl-git-flow；后者先核对目录分支，不因此强制 Git Flow；compass 本地调用专用 Skill，其他项目读自身启动方式 |
| 用例需要 API/数据库核验 | 非生产与生产各走现有对应入口，默认只读不默许写；不复制专业规则、不自动启服务 |
| 观察到页面失败，尚未核实代码，复测后通过 | 缺陷写问题、环境与数据/版本、复现证据、范围依据、预期引用和修复复测；代码确认写根因待确认；新 run 链旧 run，摘要/关键证据/临时产物分类留存 |
| 网页任务原需求 ID 为 R-123 | 映射 task=r-123，报告保留原 ID 与映射；不把 R-123 直接传 --task |
| 单独设计，已有外部用例或根本没有用例 | 外部已确认用例沿实际路径/版本，不强制总流程文件；无用例列交接缺口不造来源，旧合法批准兼容 |
| 本地 down 默认运行、仅 --purge、显式删除和共享件选择 | 默认与仅 purge 均保留证据，默认不碰 MQ；仅授权临时夹具删除，穿越/符号链接拒绝 |

修改后逐项记录实际推演范围、观察和未覆盖项；若要声称独立行为验证，必须实际通过 Herdr Pi high 调用不同会话，不用本表代替。
