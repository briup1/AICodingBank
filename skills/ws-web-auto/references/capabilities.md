# 已验证能力与限制

日期：2026-10-14；工具：opencli 1.8.7，Node.js 22.22.0，macOS本机Chrome。
这不是任意网站能力承诺。工具版本、页面机制或隔离方式变化时只重验受影响项。硬上限始终3，不做更高并发实验。

| 能力 | 实际验证与边界 |
|---|---|
| 真实网页查询 | Compass Beta 8个独立会话按3+3+2执行。批内依次发送、服务端运行重叠，不等同于同时浏览器动作。响应与页面集合逐项核对，场景6存在页面按价格重排问题，未宣称全验收通过 |
| 真实网页普通输入/异步下拉/价格单元格 | Compass运价样本录入成功；为单任务经验，不推导为真实站点并发写入能力 |
| 本地三页面隔离 | 三个opencli session各自tab new，任务值互异；回执task/origin/destination/price均正确，每页提交次数1 |
| 三页面普通填表与异步下拉 | 本地夹具通过；必须等 `#destination:not([disabled])`，未等待首次失败，不视作支持盲填 |
| 三页面焦点型表格编辑 | **未通过**：click后fill编辑框发生not_editable；可能受跨tab焦点/失焦或number输入支持影响，未独立定位根因。默认串行，不重放未知提交 |
| 三页面原子DOM编辑 | 本地夹具在单次eval内激活单元格、设置值、派发blur并提交本地表单通过，回执逐字段assert通过。仅证明这个原生夹具，不能套用Vue/VXE等组件或绕过框架状态 |
| file URL | 当前opencli拒绝file://，只能http/https。夹具用临时127.0.0.1 HTTP服务验证，结束关闭，不对外监听 |
| 并发提交真实业务表单 | **未验证**；本地回执通过不等于外部提交通过，需具体环境及写授权 |

## 回归方法

1. `node --test <skill>/scripts/self-test.mjs` 验证目录、并发上限、失败/超时及8任务排队。
2. 启动仅127.0.0.1、随机端口的临时静态服务提供 `assets/form-lab.html`，记录端口和PID，结束关闭；不安装服务、不开放局域网。
3. 创建最多3个独立tab，用不同task与origin填入，每页等待异步候选并选`origin-N-b`。
4. 表格焦点敏感链默认串行；若实验并发必须单列结果，不将失败掩盖成“全部通过”。
5. 提交本地表单后回读receipt，断言task、origin、destination、price和submissions=1；verify模式截图并查看。严禁自动重试不确定的业务提交。

运行证据默认在用户级state/web-task/runs；具体URI和业务数据保存在当次result.md，不复制客户数据进此共享记录。此次未测吞吐上限、真实多用户隔离、跨域iframe、验证码、文件上传和复杂组件并发。
