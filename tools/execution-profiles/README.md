# 执行配置

状态：仅定义归宿，尚无生效配置，也未改变现有 Agent 启动方式。

执行配置只描述 Agent 工具、模型、推理配置、适用任务、成本约束和升级条件；岗位手册引用配置，不在这里再定义“研究员/开发者”的职责。一个岗位可有多种执行配置，一个配置可被多个岗位引用。

后续配置须核验当前工具支持并记录验证状态，不猜测 CLI 参数。可共享的意图与默认选择可版本化，实际本机覆盖放 Git 忽略的本目录 *.local.yaml；密钥仍放工具自己的安全存储。

现有通过 Herdr 启动 Pi、显式 high 等约定保持有效。差异化模型是后续目标，不在骨架中暗改该约定。选择轻量模型按任务风险和证据要求，不把所有 Git/检索任务一律视为简单。

配置不能授予发布、凭证访问或外部写权限。启动、就绪检测、切换与失败恢复都需要后续实现和真实验证。
