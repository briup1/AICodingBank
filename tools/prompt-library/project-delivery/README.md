# 项目经理驱动的全流程交付

**出处**：用户 2026-11-15 提供。

**核心主张**：让 AI 以项目经理身份对已批准目标的落地结果负责，统筹调研、需求、方案、开发、测试、审查和验收；只有目标真实达成并完成必要验证后才能交付。

**适用前提**：目标已经批准，且任务需要跨阶段推进、多人或多角色协作、独立测试/审查，或需要明确授权与停止条件。

**不适用**：简单事实查询、纯只读分析、一次性小改动，以及尚未形成目标和范围的探索型需求。探索型需求应先使用需求澄清或设计类提示词。

## 使用边界

- 这条提示词可以作为一条任务的总提示词，再按实际任务补充目标、范围、验收标准和授权边界。
- “独立上下文”“独立审查”“真实环境验收”只有在实际使用独立执行者、指定环境和可核对证据时才成立。
- 提示词中的角色分工不自动授予代码、数据、部署、生产或外部系统操作权限。
- 需要具体执行流程时，仍应遵循目标项目的 `AGENTS.md`、项目规则和适用 Skill。
