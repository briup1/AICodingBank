# 提示词工作台 · 交互原型

状态：待用户确认；不是正式应用。

## 目标

通过网页快速查找、使用和编辑个人提示词。正式版拟纳入个人工作台 Git 管理；不自动提交或推送。

## 本原型能体验什么

- 按标题、用途、标签或正文关键词搜索，按分类筛选；空格分隔的词须全部命中，搜索不具备语义理解。
- 查看详情、填写 `{{变量}}`、预览和复制；浏览器拒绝复制时可手动复制。
- 演示新建、编辑、删除和未保存变更提醒；变量支持多行，切换条目时在当前页面会话中保留。
- 数据仅存在于当前页面会话，刷新即重置。不读取或写入现有提示词库，不请求网络。
- 内容是现有提示词 Markdown 中代码块的生成快照，包含一条标记为「结构模板」的非可执行提示词。状态与用途来自源文件，未虚构验证结果。
- 更新源文件后，运行 `python3 tools/prompt-library/prototype/generate.py` 再刷新页面。生成只更新原型快照，不修改源 Markdown；网页编辑仍不会写回源文件。

勾选后生成可复制的 Agent 提示词。网页不删除 Skill；执行前须核实影响、恢复方式并取得本次明确批准。扫描快照包含本机路径，保存在 `skills.generated.js`，不纳入 Git；分享提示词前注意其中的路径信息。扫描会覆盖这份生成文件。

## 拟开发范围（待确认）

本地网页 + 仅本机访问的服务 + 单条提示词单个 JSON 文件。网页完成增删改查；保存应校验内容、检查并发修改、限制写入目录并阻止外部网页利用本地服务写文件。实际启动方式、文件格式和既有 Markdown 的兼容或导入策略在正式开发前确定。

已有 Markdown 保持不变，不自动迁移或删除。不同 worktree 中的数据归属和同步方式需要在正式开发前明确，不假设自动共享。

## 拟验收

1. 启动后可在本机打开网页；无需登录或外部服务。
2. 新建、编辑并保存后，刷新和重启服务仍可读取；数据对应 Git 可追踪的文件。
3. 标题、用途、标签、正文可检索；空结果和命中字段清晰可见。
4. 变量填写后，预览与复制一致；未填变量和复制失败有明确提示及处理方式。
5. 编辑未保存时离开有提醒；同时编辑同一条时不静默覆盖；保存失败不显示成功。
6. 删除需确认，不以 Git 能恢复尚未提交的内容作保证。
7. 不自动修改现有 Markdown、不提交或推送 Git；不访问外部网络。

## 不在第一版范围

账号、云同步、多人协作、AI 自动生成与语义检索、模型调用、自动 Git 提交推送、网页直接删除 Skill。
