本次将执行层从 OpenCLI 改为 Ego。已读取本机 `ego-browser skill` v2.1.0 指南；指南确认有 TaskSpace、页面快照、输入点击、截图、文件上传下载、控制权交接等 API，但这只证明接口文档存在，不证明真实站点可靠或性能优于 OpenCLI。登记的 verified 清空，待真实场景验证后再更新，不自动安装、升级或改变宿主链接。

| 项目 | 当前判断与边界 |
| --- | --- |
| 登录复用 | 使用 Ego 已有登录环境；不保证自动读取其他工具认证状态。真实账号/企业须核对，失效交人工，不绕过验证码 |
| 单任务多页 | 一个目标默认一个 TaskSpace，可按需创建多 Page；同页动作串行，不把页面句柄存在当作页面已创建 |
| 后台与并发 | Ego 提供 Space，不等于无头运行或不受资源限制；本流程最多3活跃任务不是产品性能上限。真实页面并行尚未验证，先单任务，再经明确授权验证独立只读并行 |
| 浏览器/业务隔离 | Space 不等于不同后台账号；同企业同记录仍可能互相影响，写入依赖与焦点敏感表格串行 |
| 截图与结果 | verify/mixed 关键状态截图并实际查看，写本轮 evidence；不能以接口成功代替页面核验 |
| 交接与收尾 | 正常完成等待 finish；人工 handOff 后确认再恢复。异常/用户接管停止，不用 finally 强关，不声称退出 CLI 就清理完成 |
| Playwright 关系 | Ego 自定义 API 不是 Playwright Test，不运行既有 spec；固定脚本回归继续用项目 Playwright 与已确认登录入口 |

## 最小验证路径（获准后执行）

1. **真实登录只读**：进入约定业务页，核对环境、账号、企业和角色。记录脱敏身份匹配结果，不落盘 Cookie/Token；需补登时交接，无法确定身份即阻塞。
2. **本地单页交互**：以仅监听 127.0.0.1 的临时静态服务提供 `assets/form-lab.html`（无外部业务请求）。普通输入、等待异步候选、表格编辑、提交本地回执，逐项核对 task/origin/destination/price 和提交次数1；关键截图查看后保存。
3. **多页/并行**：先在同一 Space 验证多页归属；仅在用户明确请求独立多任务后，最多3个 Space 用不同输入验证只读/本地隔离。焦点敏感编辑先串行，未通过单列，不以 DOM 原子修改掩盖真实组件交互失败。
4. **下载与证据**：用可信本地夹具或已授权站点验证下载完成后保存至本轮绝对路径，核对文件内容而不是仅看存在。用例测试不多建 run.json/result.md，原失败不覆盖。
5. **控制权**：正常 finish、不影响用户页面；handOff → 用户确认 → 同空间恢复；异常/用户接管立即停，不重播未知提交。错误状态需要单列可恢复和未知部分。
6. 本地夹具通过不能推导真实 Vue/VXE、文件上传、跨域 iframe 或业务并发提交通过。真实写入另需具体授权；不拿公司站点做无授权容量或故障实验。结束只关闭本任务临时服务并保留证据，不清理历史空间。

本轮未执行以上浏览器场景，不给吞吐、节省内存、最大并发或完全替代的保证。通过范围和限制以具体运行记录为准。
