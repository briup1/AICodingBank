## 身份字段

只保留本项目确实需要的字段：

| 外部字段 | 本地字段 | 必填 | 校验与说明 |
| --- | --- | --- | --- |
| external user id | `external_user_id` | 是 | 保留字符串，不转数字 |
| display name | `display_name` | 视页面 | 只用于展示 |
| enterprise id | `enterprise_id` | 视业务 | 企业型产品必须可信且稳定 |
| enterprise name | `enterprise_name` | 否 | 展示字段，不作为授权依据 |

## 本地映射决策

- 外部 `user_id` 是否可以直接成为本地主键：默认否。
- 本地用户唯一键：由目标项目决定。
- 本地企业 / Tenant 唯一键：由目标项目决定。
- 个人身份是否允许：必须明确，不能由缺失企业字段自动推断。
- 一个用户是否可以属于多个企业：必须明确切换和会话失效语义。
- 一个身份是否可以进入多个产品：每个产品单独执行授权。
- 用户注销、企业撤权和凭证失效如何传播：必须明确到 Session、Grant、Request / Run。

## 接入前门禁

只有以下项目均已确认，才进入实现：

- [ ] 登录入口和 callback 契约已确认；
- [ ] 强制重新认证入口已确认，或明确不支持；
- [ ] 身份核验接口和可信字段已确认；
- [ ] 外部凭证的生命周期和存储边界已确认；
- [ ] 本地 Session、Tenant、Subject、Grant 的 Owner 已确认；
- [ ] 外部系统写操作、权限修改和生产数据范围已排除或获得明确授权；
- [ ] 失败和上游不可用时不会静默降级到更高权限。
