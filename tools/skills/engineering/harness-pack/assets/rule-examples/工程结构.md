## 目录与模块职责


```text
src/
  TodoPage.tsx       待办列表与交互，展示操作结果
  todo-service.ts    新增、完成待办的业务处理
  todo-storage.ts    待办数据的本地读写
tests/
  todo-service.test.ts    业务规则测试
  todo-storage.test.ts    本地存储读写测试
```

页面通过服务操作待办，不直接读写本地存储；存储模块不依赖页面。

## 依赖与运行链路

以“把买牛奶标为已完成”为例：

```text
用户勾选“买牛奶”
  → TodoPage 将待办 ID 交给 todo-service
  → todo-service 将该条待办设为已完成
  → todo-storage 写入浏览器 localStorage
  → 写入成功，页面显示已完成；写入失败，页面保留原状态并提示失败
```

`todo-service` 决定状态如何变化，`todo-storage` 负责持久化；页面不维护另一套完成规则。更新只影响指定 ID 的待办，不改变其他待办。

## 常见改动落点

| 要改什么 | 主要落点 | 直接影响 | 最小验证 |
|---|---|---|---|
| 完成后的展示样式 | `src/TodoPage.tsx` | 列表展示，不改变存储内容 | 页面核对未完成、已完成两种状态 |
| 完成状态的处理规则 | `src/todo-service.ts` | 页面结果及写入内容 | `tests/todo-service.test.ts`，含目标 ID 和其他待办不变 |
| 本地存储读写方式 | `src/todo-storage.ts` | 保存及刷新后的恢复 | `tests/todo-storage.test.ts`，并核对刷新后仍为已完成 |

验证入口与通过标准见同目录[测试规范](测试规范.md)。
