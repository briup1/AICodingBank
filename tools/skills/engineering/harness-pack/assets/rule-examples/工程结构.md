# 工程结构

> 虚构成稿，仅示范组织与表达，不是运行证据。共用输入及局部范围见[业务模型](../wiki-examples/业务模型.md#角色与能力边界)；路径、技术栈和约束不能复制成目标项目事实。

范围：本地待办的完成操作（局部示范）；状态：当前；依据：虚构 src/、package.json、测试设定。下述“当前”指示例设定，组织与命名为默认实践。

## 目录与模块职责

### 目录结构

```text
src/
├── TodoPage.tsx
├── todo-service.ts
└── todo-storage.ts
tests/
├── todo-service.test.ts
└── todo-storage.test.ts
```

### 架构分工

| 文件 | 职责 |
|---|---|
| src/TodoPage.tsx | 列表交互、按 ID 采用返回结果、失败提示 |
| src/todo-service.ts | Todo 导出类型、complete(id) 完成规则 |
| src/todo-storage.ts | 浏览器 localStorage 读写 |
| tests/todo-service.test.ts | 业务规则与保存失败验证 |
| tests/todo-storage.test.ts | 本地存储读写验证 |

## 依赖与运行链路

### 组件依赖

| 组件 | 依赖对象 |
|---|---|
| TodoPage | todo-service 导出的方法与 Todo 类型 |
| todo-service | todo-storage |
| todo-storage | 浏览器 localStorage |
| 服务测试 | 正式 todo-service，替换存储边界 |
| 存储测试 | 正式 todo-storage |

### 操作链路

```text
勾选“买牛奶”(todo-1) → TodoPage → complete(id)
  → todo-storage 保存 → 成功返回目标对象 → 页面按 ID 更新
  └─ 保存失败 → 页面保留原展示并提示
```

## 常见改动落点

### 文件放置规则

| 新增对象 | 路径 / 接入点（默认实践） |
|---|---|
| 展示组件 | src/{组件名}.tsx，由 TodoPage 组合、传入数据与回调 |
| 待办业务操作 | src/todo-service.ts 导出方法，由页面导入绑定 |
| 存储格式/适配 | src/todo-storage.ts |
| 规则/存储测试 | tests/todo-service.test.ts / todo-storage.test.ts |

### 命名规范

| 对象 | 格式 | 示例 |
|---|---|---|
| 页面/展示组件 | PascalCase TSX | TodoPage.tsx；拟抽取组件可用 TodoRow.tsx |
| 业务/存储模块 | 小写连字符 | todo-service.ts、todo-storage.ts |
| 操作方法 | lowerCamelCase 动词 | complete(id) |
| 测试文件 | 模块名.test.ts | todo-service.test.ts |

### 关键结构约束

1. 已确认（示例设定）：页面经服务操作待办，只有存储模块读写 localStorage。
2. 默认实践：存储模块不反向依赖页面，页面不实现第二套完成规则。
3. 已确认（示例设定）：只更新目标 ID；保存成功后才采用完成结果，失败不展示成功。

### 修改与验证指导

| 改动 | 入口 / 关联组件与参考 | 最小验证 |
|---|---|---|
| 完成展示 | TodoPage，消费 complete(id) 结果 | 未完成/已完成展示；保存失败保留原状态 |
| 完成规则 | todo-service.complete → todo-storage → TodoPage | todo-service.test：目标更新、其他待办不变、保存失败 |
| 存储格式 | todo-storage → todo-service/页面刷新恢复 | todo-storage.test：读写；增加旧数据兼容及浏览器刷新读回 |
| 取消完成（拟采用，待确认） | todo-service 新导出 reopen(id)，参考 complete 的按 ID 更新/保存后返回；TodoPage 绑定独立入口 | 先确认重复/未知 ID/失败语义；补服务及页面验证，联动业务/数据/接口正文 |

调用与失败写法见[编码规范](编码规范.md)，验证选择与证据边界见[测试规范](测试规范.md)。
