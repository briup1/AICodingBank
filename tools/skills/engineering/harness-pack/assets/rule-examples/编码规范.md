## 组件规则

### 页面不直接操作持久化

#### 范围与性质

已确认（示例设定）：适用于 src/TodoPage.tsx 的待办更新。页面调用 todo-service；只有 todo-storage 读写 localStorage。职责依据见[工程结构](工程结构.md)。

#### 正确与错误示例

同样是把待办设为已完成，差别在于是否绕过业务处理和存储边界：


```ts
// 正确：页面交由服务处理，成功后展示结果；失败时保留原状态并提示。
try {
  const updated = await todoService.complete(todo.id);
  showTodo(updated);
} catch {
  showError("保存失败，请重试");
}

// 错误：页面直接写存储，绕过服务，并可能覆盖其他待办。
localStorage.setItem("todos", JSON.stringify([{ ...todo, completed: true }]));
```

#### 例外与依据

todo-storage 内部可以调用 localStorage；页面和服务不能以“只改一个字段”为由绕过它。这里的“已确认”来自示例协作约定，不是根据现有代码出现次数推断出的硬规则；未声称已有自动门禁。
