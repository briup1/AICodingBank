## 组件规则

### 页面与服务

```text
TodoPage → complete(id) → todo-storage 保存 → 返回目标对象 → 页面更新同 ID 项
```

| 场景 | 沿用写法 | 禁止 / 例外 |
|---|---|---|
| 页面更新 | 已确认（示例设定）：经服务操作待办，成功才展示结果 | 不直接写 localStorage；底层存储模块内部可写 |
| 服务处理 | 按 ID 生成目标更新结果，经存储保存后返回 | 不覆盖其他待办；不在页面复制完成规则 |
| 保存失败 | 存储抛错，服务将拒绝交给页面 | 不吞异常返回空成功值，不把待提交对象当已保存 |

```ts
// 正例：页面消费保存后的结果；失败保留原展示。
try {
  const updated = await todoService.complete(todo.id);
  showTodo(updated); // 替换同 ID 项，不覆盖整份列表。
} catch {
  showError("保存失败，请重试");
}
// 反例：绕过服务/存储边界，还可能覆盖其他待办。
localStorage.setItem("todos", JSON.stringify([{ ...todo, completed: true }]));
// 反例：保存失败仍在 catch 中 showTodo({ ...todo, completed: true })。
```

以上边界由示例协作约定与 src/TodoPage.tsx、todo-service.ts、todo-storage.ts 设定，不以出现次数授予强制性。调用条件见[接口协议](../wiki-examples/接口协议.md)。
