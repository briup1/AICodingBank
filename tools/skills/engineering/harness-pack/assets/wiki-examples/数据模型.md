# 数据模型

> 虚构成稿，输入及局部范围见[业务模型](业务模型.md#角色与能力边界)；仅示范表达，不是实测证据，设定不得移植为目标事实。

范围：待办完成操作的数据（局部示范）；状态：当前；依据：虚构 Todo、todo-service 与 todo-storage。“当前”仅指示例设定。

## 数据所有权总览

| 数据 / 状态 | 决定 / 保存者 | 存储 / 消费者 |
|---|---|---|
| 待办与完成状态 | todo-service 决定变化，todo-storage 序列化保存 | localStorage；页面消费服务结果 |
| 列表与错误提示 | TodoPage | 展示副本，不是另一份持久化事实 |

## 对象与状态

### Todo 与展示副本

类型定义随 `src/todo-service.ts`，序列化随 `src/todo-storage.ts`；这里只摘要修改必需约束，不复制完整类型。

| 项目 | 约束 / 状态 |
|---|---|
| 关联身份 | ID 定位存储对象与页面项，title 仅展示，completed 表示完成 |
| 局部迁移 | todo-1: false→true；todo-2 不变；取消完成/删除未设定 |
| 隔离 | 按站点来源与浏览器上下文；同源同上下文标签页不隔离，无账号/租户隔离 |
| 失败 | 保存拒绝，不返回成功；页面保留原展示。不据此承诺底层事务/全部回滚 |

```text
服务按 ID 构造更新 → 存储保存 → 返回目标 → 页面替换同 ID 项
  保存失败：拒绝交给页面 → 保留展示、提示
刷新恢复：读回持久数据 → 页面（装载签名未提供，须另查）
```

同/跨标签页并发顺序、损坏恢复和自动重试未定义，不能从单次成功推断锁或恢复能力。业务前提与结果由[业务模型](业务模型.md)维护。

## 修改与验证落点

| 改动 | 定义 / 直接消费者 | 验证重点 |
|---|---|---|
| 状态含义 | todo-service 类型/处理 → TodoPage | todo-service.test：目标与其他项、保存失败 |
| 序列化格式 | todo-storage → 服务/刷新装载 | todo-storage.test、旧数据兼容、真实刷新读回 |
| 取消完成（拟采用，待确认） | 服务新增 true→false 操作，参考 complete，不改为自动切换 | 先确认重复/失败语义，联动业务/接口与页面 |

接入方式见[工程结构](../rule-examples/工程结构.md#常见改动落点)，选测与证据见[测试规范](../rule-examples/测试规范.md)，不另抄用例。
