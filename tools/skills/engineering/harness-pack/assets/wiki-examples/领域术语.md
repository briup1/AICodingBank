# 领域术语

> 虚构成稿，输入及局部范围见[业务模型](业务模型.md#角色与能力边界)；仅示范表达，不是实测证据，设定不得移植为目标事实。

范围：待办完成操作的名称（局部示范）；状态：当前；依据：虚构需求文案、Todo 类型与页面。“当前”仅指示例设定。

## 术语与名称对应

| 名称 | 代码对应 | 含义 / 不可混用点 |
|---|---|---|
| 待办 | Todo；src/todo-service.ts 导出类型 | 一件事，以 ID 而非标题区分身份；同名不合并 |
| 完成 | completed；complete(id) | 事情已办妥，不表示删除，也不自动代表保存成功 |
| 保存 | src/todo-storage.ts | 写入当前浏览器 localStorage，不是仅改展示或内存 |

## 易混淆边界

“本地”按站点来源及浏览器上下文隔离，不是个人账号隔离；同一上下文的数据不能承诺按使用者互不可见。

```text
勾选“买牛奶” → 服务保存 → 成功结果 → 页面完成展示
```

业务成功/失败规则见[业务模型](业务模型.md)，状态/隔离机制见[数据模型](数据模型.md)，不在词表再定义一套。

## 来源与未覆盖

- 来源为上述虚构文案、类型及存储设定，无真实术语核验记录。
- “取消完成”是否独立动作尚待确认；首次提出时定名，不将 complete 猜成通用切换开关。
