# 接口协议

> 虚构成稿，输入及局部范围见[业务模型](业务模型.md#角色与能力边界)；仅示范表达，不是实测证据，设定不得移植为目标事实。

范围：完成待办的页面到服务调用（局部示范）；状态：当前；依据：虚构导出类型与调用设定。“当前”仅指示例设定。

## 范围与权威契约

| 边界 / 消费者 | 定义 Owner |
|---|---|
| complete(id) / src/TodoPage.tsx | src/todo-service.ts 的导出签名、Todo 类型 |

本例只有浏览器内模块契约，无 HTTP/队列/外部接入；不代表全项目接口索引。

## 通用约定

- 当前浏览器内调用，无账号/Token/HTTP 状态码，不由此推导允许对外暴露数据。
- 成功由 Promise 返回，保存失败以拒绝交给页面，不预设网络重试或统一响应包装。
- 状态/存储边界见[数据模型](数据模型.md)，用户可见结果见[业务模型](业务模型.md)。

## 接口与消息条目

### todoService.complete(id)

| 调用项 | 条件 / 结果 |
|---|---|
| 方向/签名 | TodoPage → todo-service；`complete(id: string): Promise<Todo>` |
| 输入 | 列表中已有且尚未完成的待办 ID，不是标题 |
| 成功 | 保存后的目标对象：字符串 id/title、布尔 completed=true；ID 不变，不是整份列表 |
| 副作用 | 只保存目标完成状态，其他待办不变 |
| 失败 | Promise 拒绝；页面保留原展示并提示，不承诺特定错误码或全部底层回滚 |
| 未定条件 | 未知 ID、重复调用、并发未定义；不猜幂等、自动切换或重试 |

最小合法调用（输入见共用设定）：

```ts
const updated = await todoService.complete("todo-1");
// { id: "todo-1", title: "买牛奶", completed: true }；todo-2 不变。
```

```text
调用 → 服务更新 → 存储保存 → 成功返回 / 失败拒绝
```

| 修改 | 消费者 / 验证 |
|---|---|
| 入参、结果或错误交付 | TodoPage、tests/todo-service.test.ts；合法目标、其他项不变、保存失败 |
| 保存机制 | todo-storage 与浏览器刷新读回；替身不证明真实持久化 |

没有版本化外部协议不等于改签名天然兼容。错误捕获正反例见[编码规范](../rule-examples/编码规范.md)，真实保存的证据要求见[测试规范](../rule-examples/测试规范.md)。
