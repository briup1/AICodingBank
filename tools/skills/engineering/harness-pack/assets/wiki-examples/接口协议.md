## 通用约定

调用发生在当前浏览器内，无账号鉴权、Token、HTTP 状态码或网络重试约定。这里“无账号”不是允许把本地数据暴露给外部调用者。

成功通过异步返回值交付结果，保存失败通过 Promise 拒绝交付给页面；展示及失败提示见[业务模型](业务模型.md)。状态与存储边界以[数据模型](数据模型.md)为准。

## 接口与消息条目

### todoService.complete(id)

#### 用途与身份

调用方向：src/TodoPage.tsx → src/todo-service.ts。用于把已存在、尚未完成的目标待办设为已完成；调用方从列表对象取得 ID，不用标题代替 ID。

#### 请求与结果

ID 与返回 Todo 的类型以示例 src/todo-service.ts 的导出定义为准。假设列表中“买牛奶”的 ID 为字符串 todo-1，一个最小调用是：


```ts
const updated = await todoService.complete("todo-1");
// updated.id 为 "todo-1"，updated.completed 为 true。
```

返回值是完成保存后的目标待办，ID 不变、completed 为 true；不是整份列表，也不是统一响应包装。此片段只展示合法成功调用，错误分支由调用方按通用约定处理。

#### 错误与副作用

成功会保存目标待办的完成状态，不应改动其他待办。保存失败不返回成功结果，页面不能把点击本身当作成功证据。

待确认：未知 ID、已经完成后重复调用及并发调用的行为；当前示例不据此承诺幂等、自动切换状态或特定错误码。涉及这些调用前先确认预期，不由消费者猜测。

#### 兼容与验证

直接消费者为 src/TodoPage.tsx。调整入参、返回对象或失败交付方式时，同时核对页面和 tests/todo-service.test.ts；本地真实保存另按[测试规范](../rule-examples/测试规范.md)核对，替身测试不能证明浏览器持久化。
