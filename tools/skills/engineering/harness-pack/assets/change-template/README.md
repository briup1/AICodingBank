# 需求与变更归档

新需求在本目录按 YYYY-MM-DD-主题 建立，日期为首次建档日期。沿用已存在需求目录，不复制另一个版本；同需求修订原正文与受影响用例，历史批准和执行证据保留。

需求：requirement.wl-req-confirm.md（HTML同源生成）；方案：design.wl-design-doc.html；用例：test-cases.wl-qa-test-planner.md（HTML按需同源生成）；附件：assets；结果用项目现有执行记录格式，新项目放本需求test-runs/轮次/result.json，原始证据按需放evidence。归档目录不等于提交许可：需求/方案/用例和必要结论按约定跟踪；原始响应、截图、日志执行前确定忽略或受控保存方式，提交前检查脱敏与暂存清单，不含密码和登录态。向执行方明确传入轮次目录，不再复制一份结果；已有记录保留原位置并引用。

只有长期规则、模块职责/关键契约或须保留理由的重要取舍变化，才在同需求目录更新规范变更.md；局部修复、链接更正和一般事实补齐直接修改原文，不为每次提交建记录。它只写变化、更新位置和确认/验证引用，不复制需求、样本、用例或结果。无需求的独立资料维护按日期-维护主题建目录，仅存必要记录。无变化不建空目录。
