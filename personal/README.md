# 董事长与个人上下文

董事长指真实用户，不是一个 AI 岗位。项目经理可以提出建议，不能把推断写成用户批准；本轮不创建“AI 董事长”。

## 信息的唯一归宿

| 信息 | 归宿 | 边界 |
| --- | --- | --- |
| 稳定身份、长期方向、表达特点、公开定位 | 本目录的 profile.local.md | 私人本机文件；仅写用户确认内容 |
| 现有工程偏好、本机路径、项目与知识库指针 | [WORKBENCH.local.md](../WORKBENCH.local.md) | 本轮保留权威源，不复制正文 |
| 阶段目标 | 对应项目或经确认的目标记录 | 带时间与复核点，不当永久画像 |
| 单次任务目标与允许操作 | 本次任务/项目记录 | 不升级成长期授权 |
| 对外介绍与品牌资产 | 用户确认的内容项目 | 内部画像不能自动公开；暂无独立品牌资料，不虚构 |
| 凭证 | 工具规定的安全存储 | 不进入画像、岗位或版本库 |

[画像结构示例](profile.example.md)不含真实私人资料。profile.local.md 已由 Git 忽略；本地文件不是跨机器同步或备份方案。没有该文件时询问必要背景，不从缺失内容猜测。

读取只限本次需要；不得把内部画像整体传给每个岗位或写进公开作品。新资料优先复用已有权威源，以指针连接，不新建多份偏好正文。
